## 建议阅读顺序

**完全没接触过 PZ modding**：`01` → `03` → `04` → `07`，先跑通一个纯脚本物品。

**会写代码、想直接做机制类 mod**：`01` → `03` → `05`（Lua 部分）→ `10`（查 API 的方法）。

**已经动手、卡住了**：直接看 `08`（踩坑清单）和 `10`（数据获取）。

## 关于附录 B

附录 B 是这份手册里**最特殊的一节**——它不是 PZ 的语法文档，而是**"怎么把数据搞到手"的方法论**。

原因是 PZ 的官方 wiki（pzwiki.net）在本机被 Cloudflare 拦死、官方游戏脚本网上拿不到，很多常规查资料的路子走不通。这一节记录了：

- 哪些站点实测可用 / 不可用，以及**每个站点的具体症状**（避免重复试错）
- 绕行手法（GitHub DNS 劫持下怎么取文件、怎么通过"抄了原版定义的 mod 仓库"反推原版数据）
- 查 API 存在性的标准流程（含一个会让你得出**错误结论**的正则坑）
- B42 武器耐久的三层系统、运行时改脚本参数的 `DoParam()`
