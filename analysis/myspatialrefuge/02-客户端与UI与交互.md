# MSR 客户端架构与交互

## 1. 入口与事件
`MSR_Main.lua:274-279` 注册 4 个（+1 条件）PZ 事件：`OnGameStart`、`OnInitWorld`（置 `worldReady`）、`OnPlayerGetDamage`（仅 `WEAPONHIT` 记时间）、`OnCreatePlayer`（存在则注册）。初始化靠 `Events.OnTick` 延迟 30 tick（Migration/继承，`MM:214-239`）。其余散在各文件：`OnPlayerUpdate`（Boundary:135）、`OnFillWorldObjectContextMenu`（Context:242）、`OnServerCommand`（Router:333、Slash:316）、`OnMainMenuEnter`（CoreAlert:74）、`OnClothingUpdated`（InventoryHooks:48）。
**Q 键轮盘**：mod 未注册任何按键、无 keybinds 文件；做法是 hook 原版 `ISEmoteRadialMenu.fillMenu(submenu)`（RadialMenu:154）——先调原函数，再 `getPlayerRadialMenu():addSlice()` 注入，`submenu` 非空时不注入（只改顶层环）；车内 hook `ISVehicleMenu.showRadialMenu`（:200）。（Q→该轮盘属原版，**推断**）

## 2. CUI_* 框架
非从零写，全部 `derive` 自原生类：`CUI_ScrollBar=ISScrollBar`、`CUI_ScrollView`/`CUI_VirtualScrollView=ISUIElement`、`CUI_ProgressBar`/`CUI_SearchBox=ISPanel`、`CUI_ToggleButton=ISButton`，仅重写 render/update。`CUI_Config` 按字号缩放的尺寸与配色；`CUI_Framework` 加载器+版本/NinePatch 探测；`CUI_Tools` 文本截断、颜色、3/9-patch；`CUI_ScrollBar` 自绘滑块；`CUI_ScrollView` 惯性滚动+裁剪；`CUI_VirtualScrollView` 对象池只渲染可见项；`CUI_SearchBox` 搜索框+清除键；`CUI_ProgressBar` 动画进度条。`CUI_Button.lua` 是 4 行空壳（仅为保住框架自检的全局）。
`CUI_FileUtils`（shared）包 `getModFileReader`/`getFileReader` 并兼容 B42+ mod id 的 `\` 前缀（先用 `getModInfoByID` 校验以免 Java NPE，:117-129）。`CUI_YamlParser`（shared）是自写的轻量 YAML 解析器：栈式缩进、行内数组/对象、注释剥离，另有带环检测的物品组展开 `$group`/`*group`（:360-397）；它读 `media/lua/shared/upgrades.yaml` 是升级数据的真实入口。

## 3. 升级界面
`MSR_UpgradeWindow`（ISPanel）三栏：`SRU_UpgradeGrid`(35%) + `SRU_UpgradeDetails`(40%) + `SRU_IngredientList`(25%)，`SRU_RequiredItems` 嵌在详情里做材料槽。数据源双重：Lua `UPGRADE_DEFINITIONS` 先加载，`upgrades.yaml` 再覆盖/扩展（UpgradeData:196-230）；`getNextLevelRequirements` 按难度 `D.core()/D.material()` 缩放数量（:376-405）。材料清单：`MSR_UpgradeItemCache` 扫玩家物品源、用 `IsItemAvailable` 剔除被事务锁定的物品（:51），`substitutes` 合并计数（:112-130），UI 显示 `have / need`、不足标红（CustomizationPanel:111-131）；库存变化由自建事件 `MSR_OnInventoryChange`（100ms 去抖）触发刷新（UpgradeWindow:243-273）。

## 4. 客户端 ↔ 服务端
`MSR_ServerCommandRouter` 是自定义协议，命名空间 `"SpatialRefuge"`，命令常量在 `00_core/Config.lua:113-149`。收用 `Events.OnServerCommand`，发用 `sendClientCommand`；下行由 `CommandHandlers[command]` 表分发 13 类，未知静默丢弃（Router:306-329）。上行在服务端 `MSR_Server:929-992`：校验 module → **速率限制**（`canProcessRequest`，`CHUNKS_READY`/`REQUEST_MODDATA`/`REQUEST_FEATURE_UPGRADE`/`REQUEST_*_SPATIAL_WELL`/`ADMIN_COMMAND` 豁免）→ 白名单 if-else 派发，未知仅记日志；`DEBUG_ADD_CORES` 另查 `isDebugAllowed`，`/msr` 走 AdminHandler:38-43 的 `isAccessLevel("admin")`。SP/MP 用 `MSR.Env.isMultiplayerClient()` 分支：MP 只发请求等回包，SP/主机本地权威执行（Teleport:229/277、UpgradeLogic:408）。MP 进场多一次握手：`TeleportTo` → 客户端等区块 → `ChunksReady` → `GenerationComplete`（Router:53-72）。

## 5. 传送
进入：轮盘 `tryEnterRefuge`（:114）→ `BeginTeleportCast`（Cast:25）经 `ISTimedActionQueue` 排 `ISEnterRefugeAction`，时长受 `faster_refuge_cast` 缩放 → `perform` 调 `EnterRefuge`：重复进场拦截 → `CanEnterRefuge`（冷却+10s 战斗封锁，TeleportCooldown:50-75）→ 存车辆数据并下车 → 存返回坐标 → SP 直传 / MP 发 `RequestEnter`。SP `doSingleplayerEnter`（:54）用 `Utils.poll` 分步：先 `teleportTo`，2-5 tick 转视角，≥20 tick 起 `StepEnterPreparation`（清僵尸/建墙/造遗物），超时回滚退出，再按超重写惩罚到 `spatialRefuge_lastTeleport`。退出：`BeginExitCast`（先清队列）→ 存 roomIds → 清返回位 → 传回原位；`MSR_Boundary` 每 2 tick 硬夹回越界坐标（:110-133）。
车辆：需 `vehicle_teleport` ≥1 级且车速为 0（否则槽位灰掉，RadialMenu:225-231）。进场存 `vehicleId/seat/x/y/z` 后 `vehicle:exit`；离场先传送到车辆坐标，再用 `OnPlayerUpdate` 轮询最多 300 次、5×5 格搜 `getVehicleContainer`，命中则对齐坐标 `vehicle:enter(seat)`+`transmitCharacterPosition`（VehicleTeleport:93-176）。

## 6. 输入与交互
- **按键**：新增 0 个；仅调试硬编码 F9（下地下室，Basement:441）。
- **轮盘项**：内 `Exit Spatial Refuge`（debug 时加 `Refuge Debug`）；外 `Enter Spatial Refuge`（+debug）；debug 子环 `Teleport to Basement`/`to Floor`/`Add 1000 Magical Cores`/`Back`；车内需升级+静止，否则显示 `Vehicle must be stopped`。
- **右键**：世界物体 `IGUI_MoveSacredRelic` 子菜单（Up/Right/Left/Down/Center，30s 冷却）、`IGUI_ManageRefuge`（开窗）、`IGUI_MoveSpatialWell`；物品栏 `IGUI_MSR_AbsorbEssence`（XPRetention:607-618）。
- **斜杠**：仅 `/msr <sub>`，hook `ISChat.onCommandEntered`（Slash:269-289）；子命令 `help/stats/list/info/inactive/purge/delete/goto/scan`（AdminCommands:483-492），需 admin，SP 本地执行、MP 走 `AdminCommand`→`AdminResponse` 回显聊天框。
- 另：遗物/边界/空间井等受保护物件屏蔽拆除、搬动与敲击（Context:257-399）。
