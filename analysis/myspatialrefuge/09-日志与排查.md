> **对象**：`mods/myspatialrefuge/`（My Spatial Refuge 1.27.1 + 我方新增功能）

## 2. 架构

```
K  (KahluaCompat)  ─┐
L  (Logging)        ├─ 三大基础设施全局，由 00_core/00_MSR.lua 按序加载
D  (Difficulty)     ─┘   （顺序：KahluaCompat → Logging → Env → FreeMode → Config → …）
```

**构建器模式**（推荐用法，53 个模块都这么用）：

```lua
local LOG = L.logger("MyModule")     -- tag ≤ 12 字符（超了会被截断，见 §5）
LOG.debug("细节：%s", value)          -- 只在调试模式下输出
LOG.info("状态事实：%s", value)       -- 总是输出
LOG.warning("异常：%s", value)
LOG.error("失败：%s", value)
```

**双输出** —— 每条日志同时进两个地方 `[文件] Logging.lua:131-141, 117-129`：

| 去处 | 实现 | 说明 |
|:---|:---|:---|
| **PZ 原生日志系统** | `_log(DebugType.Mod, formatted)` | 走游戏自己的日志通道（`-debug` 的控制台窗口里能看到） |
| **独立日志文件** | `writeLog("MySpatialRefuge", line)` | `LOG_FILE = "MySpatialRefuge"` `[文件] Logging.lua:51` |

**性能取向**（说明它是认真做的，不是随手 print）：缓存全部全局函数（`local _getDebug = getDebug`、`_format = string.format`…）`[文件] :31-45`、缓存标签列 `_tagCache` `[文件] :60,90-92`、标签截断 + 定宽补齐。

## 3. 输出格式

### 3.1 console.txt

```lua
-- [文件] Logging.lua:137
local formatted = _format("[%s][%s:%s] %s", getOrigin(), MOD_TAG, tagTrimmed, msg)
```

```
[来源][MSR:标签] 消息
```

| 级别 | console 里的实际形态 | 有无级别标记 |
|:---|:---|:---|
| `LOG.info` | `[SHARED][MSR:FreeMode] Debug free mode: ACTIVE ...` | ❌ **没有** |
| `LOG.debug` | `[SHARED][MSR:Window] Upgrade click: expand_refuge -> level 2` | ❌ **没有** |
| `LOG.warning` | `[WARN] [SHARED][MSR:FreeMode] ...` | ✅ 前缀在最前 |
| `LOG.error` | `[ERROR] [SHARED][MSR:BuildableD..] ...` | ✅ 前缀在最前 |

> ⚠️ **info 与 debug 在 console 里长得一模一样**，区分方式只有"debug 在非调试模式下压根不出现"。
>
> ⚠️ **`[WARN] ` 与后面的 `[SHARED]` 之间有一个空格** —— 从 `toConsole("[WARN] ", tag, msg)` 的字符串常量来的 `[文件] :200,215`。

### 3.2 「来源」是什么

```lua
-- [文件] Logging.lua:67-78
if _isClient() then _origin = "CLIENT"
elseif _isServer() then _origin = "SERVER"
else _origin = "SHARED" end
```

| 环境 | `isClient()` | `isServer()` | 来源标记 |
|:---|:--:|:--:|:---|
| **单机** | false | false | **`SHARED`** ← 你日常看到的就是这个 |
| 多人客户端 | true | false | `CLIENT` |
| 专用/Coop 服务端 | false | true | `SERVER` |

> **别按 `[CLIENT]` 去搜单机日志**，单机是 `[SHARED]`。

### 3.3 独立日志文件

```lua
-- [文件] Logging.lua:117-129
-- 普通:  [%-5s]%s%s              → [INFO ][FreeMode]    message
-- 调试:  [%d][f:%-6d][%-5s]%s%s  → [1234567][f:4242  ][DEBUG][FreeMode]    message
```

| 级别 | 是否写入文件 | 文件内格式 |
|:---|:---|:---|
| info / warning / error | **总是写** | `[级别]` + 标签列（补齐到 14 宽）+ 消息 |
| debug | **只在调试模式写** | 多带 `[毫秒][f:帧号]` |

> 文件头注释声明 `[date]` 前缀由 `writeLog()` 经 `ZLogger` 自动加上 `[文件] Logging.lua:8`。
> ⚠️ **确切目录未能离线确认**（本机无游戏；本地资料只查到 `zombie.core.logger.ZLogger` 这个类名）。落地时在 Zomboid 目录下找名为 `MySpatialRefuge*` 的文件即可。

> 💡 **重要推论**：**不带 `-debug` 也能拿到 mod 的 info/warn/error**（落在独立日志文件里），只是拿不到 debug 细节与 PZ 的控制台窗口。`-debug` 是"控制台窗口 + Lua 报错定位"的必需品，不是"看 info 日志"的必需品。

## 7. 既有瑕疵：两套 debug 判定不一致

| 判定 | 依据 | 缓存 |
|:---|:---|:---|
| `MSR.Env.isDebugEnabled()` | **三个兜底**：`getDebug()` / `getCore():getDebug()` / `isDebugEnabled()` | 不缓存 |
| `L.isDebug()`（控制 `LOG.debug` 是否输出） | **只有 `getDebug()`** `[文件] Logging.lua:31,150-155` | **首次调用即缓存** |

**后果**：可能出现 **UI 显示「调试：免费」但 `LOG.debug` 全被抑制** —— 看起来像功能没生效或 mod 坏了。

**我方对策**（免费模式）：开局播报 + 不一致时额外 warning，见 [§8](#8-我方新增的日志)。**没有去改 `Logging.lua`**（那是原有基础设施，改它会影响全库 429 处调用）。

## 8. 我方新增的日志

**原则**：
- **状态事实 → `info`**（免费模式是否生效、每次免单）
- **高频细节 → `debug`**（点击到达、放置请求）
- **异常 → `warning`**（探测不一致、sprite 解析失败、未知建筑）

| 位置 | 内容 | 级别 |
|:---|:---|:---|
| `FreeMode.AnnounceState` | 免费是否生效 + **三个探测值** + `debugLogging` | info |
| `FreeMode.AnnounceState` | 探测不一致时的告警 | warning |
| `UpgradeLogic.purchaseUpgradeSP` | `Free mode: upgrading %s to level %s without charging` | info |
| `BuildableLogic.GenericBuild` | `Free mode: building %s at x,y,z without charging` | info |
| `SpatialWell.RequestPlacement` | `Free mode: placing Spatial Well at x,y,z without charging` | info |
| `MSR_BuildCursor.Start` / `StartMove` | 开始放置/移动哪个建筑 + 五种拒绝原因 | debug / warning |
| `MSR_BuildCursor.tryBuild` | 放置/移动请求 + 落点 + 拒绝原因 | debug |
| 三个面板的点击入口 | 点击是否到达、被防连点/材料不足/实例上限拦下 | debug |

> **为什么免费分支要用 info**：免费时不建事务，**没有 `BEGIN:`/`COMMIT:` 记录**，不补这条整笔操作在日志里静默。
> **三个 UI 文件此前没有 logger**（基线 diff 为 0），本轮各补了 `local LOG = L.logger(...)`。

## 9. 排查速查（可复制）

```powershell
# ---------- 单机：主日志 ----------
$console = "$env:USERPROFILE\Zomboid\console.txt"

# 只看"走 logger 的那套"（把 66 处裸 print 排除掉）
Select-String -Path $console -Pattern '\[MSR:'

# 免费模式：开局播报 + 每次免单（大小写敏感，注意 "Free mode: " 带冒号）
Select-String -Path $console -Pattern 'Free mode'

# 只想要"每次免单"，不要开局播报
Select-String -Path $console -Pattern 'Free mode: '

# 三条业务链路
Select-String -Path $console -Pattern '\[MSR:Exchange|\[MSR:Buildable\]|\[MSR:UpgradeLogic\]'

# 事务（扣料是否发生、锁料是否成功）
Select-String -Path $console -Pattern '\[MSR:Transaction\]'

# 只要告警与错误（注意 WARN/ERROR 的前缀在最外层）
Select-String -Path $console -Pattern '^\[WARN|^\[ERROR'
```

```bash
# ---------- Linux/跨平台同样适用（把路径换成你的 Wine/Proton 目录）----------
grep -n '\[MSR:' "${ZOMBOID_DIR:-$HOME/Zomboid}/console.txt" | tail -100
grep -n 'Free mode' "${ZOMBOID_DIR:-$HOME/Zomboid}/console.txt"
```

> **记住三件事**：① 单机来源标记是 `[SHARED]`；② 标签超过 12 字符会被截断成 `前10字符..`；③ info 与 debug 在 console 里没有级别标记，只有 `[WARN]` / `[ERROR]` 带前缀。

## 10. 给后续开发者的约定

1. **别用裸 `print`** —— 它会绕过 `[SHARED][MSR:x]` 前缀与独立日志文件，让日志变得不可筛。用 `local LOG = L.logger("Tag")`。
2. **Tag ≤ 12 字符**，否则被截断、按名字 grep 搜不到（要么取短名，要么记住截断后的形式）。
3. **状态事实用 `info`，细节用 `debug`** —— 因为 debug 占全库 69%，而它默认不输出；把关键状态塞进 debug 等于没写。
4. **免费模式下额外补一条 info** —— 否则该操作无事务日志、在日志里静默（见 `FreeMode.EffectiveCost` 的三处调用点）。
5. **不要改 `Logging.lua`** 去"修正"两套 debug 判定 —— 429 处调用都依赖它现有行为；需要诊断时用 `FreeMode.DescribeProbes()` 那种"把探测值打出来"的方式绕开。
